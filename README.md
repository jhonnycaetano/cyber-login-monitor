# Cyber Login Monitor

## Descrição

Projeto desenvolvido em MySQL para monitoramento de tentativas de login e identificação de possíveis ataques de força bruta.

## Tecnologias

- MySQL
- MySQL Workbench
- Git
- GitHub

## Funcionalidades

- Cadastro de usuários
- Registro de tentativas de login
- Consulta de falhas de autenticação
- Detecção de possíveis ataques de brute force
- View para monitoramento de falhas

## Estrutura

### usuarios
Armazena os usuários do sistema.

### tentativas_login
Armazena todas as tentativas de autenticação.

## Consultas Implementadas

- Histórico de login
- Falhas de autenticação
- Ranking de usuários com mais falhas
- Detecção de IPs suspeitos
